# Meta Ads API em Markdown

Este pacote organiza a documentacao oficial da Meta Ads API, cujo nome oficial na Meta e **Marketing API**, em uma serie de arquivos `.md` para consulta e download.

Importante:

- Este material **nao e um espelho integral** da documentacao proprietaria da Meta.
- Ele foi montado como um **guia estruturado em Markdown** com cobertura dos topicos principais, links oficiais e resumos praticos.
- Data da verificacao: **2026-04-09**
- Versao mostrada pela pagina principal oficial nessa data: **v25.0**
