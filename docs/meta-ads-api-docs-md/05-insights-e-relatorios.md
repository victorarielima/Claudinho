# 05. Insights e relatorios

## Pagina oficial

- https://developers.facebook.com/docs/marketing-api/insights

## O que a secao cobre

A API de Insights e a interface principal para leitura de metricas e estatisticas dos anuncios. Ela e usada para:

- Ler performance por conta, campanha, conjunto ou anuncio
- Extrair metricas para BI e dashboards
- Fazer recortes temporais e dimensionais
- Comparar atribuicao, entrega e conversoes

## Casos de uso comuns

- Relatorio diario por conta de anuncios
- Painel por campanha e objetivo
- Exportacao de dados para data warehouse
- Diagnostico de queda de performance

## Boas praticas uteis

- Fixe janelas de tempo e timezone do relatorio
- Versione consultas importantes
- Trate paginacao, limites e possiveis atrasos de agregacao
- Documente o significado de cada metrica usada no negocio
